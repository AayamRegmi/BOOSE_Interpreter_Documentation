Class WebCanvas
WebCanvas class implements the ICanvas interface for ASP.NET Core Web API. Unlike AppCanvas, this does NOT use the Singleton pattern since each HTTP request should have its own independent canvas instance for thread safety. Generates server-side images that can be converted to Base64 for web transmission.
Syntax
C#
    public class WebCanvas : ICanvas
