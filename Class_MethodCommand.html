Class MethodCommand
Custom method declaration command that replaces BOOSE's Method class. Syntax: "method [int/real] methodName [int/real param1, int/real param2, ...]" Example: "method int mulMethod int one, int two" Handles method registration, parameter parsing, and control flow jumping.
