Class ElseCommand
Represents the 'else' branch in an if-else conditional statement. Syntax: "else" This command is reached when the 'if' condition is FALSE. When executed, it skips to the matching 'end if' command.

Method Execute
Executes the 'else' command by skipping the else block. This method is only called when the IF condition was TRUE, so we need to skip over the entire else block to the matching 'end if'. Uses nesting level tracking to handle nested if-else statements correctly.
